# bq-lite Compatibility Matrix

## Status Values

- `exact`: BigQuery-equivalent semantics implemented and covered by tests
- `compatible subset`: useful support exists, surface or edge cases incomplete
- `shim`: minimal compatibility stub for client/SDK discovery
- `unsupported`: not yet implemented
